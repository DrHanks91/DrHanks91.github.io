小车实物检查预约通知

结合前期发布的《个人招募学科竞赛种子选手筛选方案》，为有序推进选手筛选检查，现将实物作品验收预约相关事宜补充通知如下：

检查预约时间

有意向参与本次种子选手筛选的同学，可在8月31日—9月6日期间，主动联系[1]指导老师预约一对一[2]实物检查，本时段为本次筛选唯一有效检查周期。

逾期未主动预约、未完成小车实物及全套资料验收筛选的同学，将直接视为自动放弃本次筛选资格，后续不接受补约、延后检查，请各位同学严格把控时间。

检查所需准备内容

（沿用原筛选方案要求，点击链接)
参与现场检查需提前筹备完整作品及资料，缺一不可：

  • 实物作品：自主制作完成的STM32遥控小车；

  • 全套资料：设计说明书、CAD二维零件图纸、三维建模源文件；

  • 现场修改：做好现场实操修改程序、答辩答疑的准备，熟练掌握作品制作全流程。

核心规则

本次筛选全程自愿参与，无统一集中检查，全部为单人或者单队预约验收；

  • 所有组队、硬件制作、原创规范、报销资助、梯队培养、风险须知等规则，均严格按照前期发布的《个人招募学科竞赛种子选手筛选方案》执行。

个人招募学科竞赛种子选手筛选方案

发表于 2026-06-25 更新于 2026-08-28

个人招募学科竞赛种子选手筛选方案

声明：以下为个人自愿参加，出现安全问题，个人自负。与指导老师无关。

〇、宗旨

本次筛选面向意向深耕机电类学科竞赛学生，择优筛选6名长期储备种子选手，纳入梯队培养，备战后续各级学科竞赛；

本次仅做选手筛选，非赛事参赛，重点考核自主设计、硬件调试、代码编写、独立解决问题综合能力。

后续瞄准机械类专业赛事，每组至少获得两个省三奖及以上奖励。

一、筛选形式

自主制作STM32遥控小车。

二、筛选基础规则

（一）组队规则

1、1-2人完成全部制作；禁止3人及以上组队；

2、双人搭档筛选同时考核，每位成员必须精通全流程，杜绝混组队蹭名额。

（二）硬件制作要求

1、主控要求：仅限STM32裸核心最小系统板，严禁使用一体化成品开发板；

2、接线要求：无需焊接电路板，可使用面包板+杜邦线外接模块等搭接电路；

3、底盘要求：禁止网购成套成品小车底盘，全车底盘、电机固定支架、连接件必须自主三维建模设计；

4、标配外设：无线遥控手柄、车载显示屏、直流电机、驱动模块等分立模块自行搭配。

（三）基础必达功能

仅需达标基础行驶功能：无线手柄稳定控制小车前进、后退、左转、右转即可。

其余车载显示屏功能、外设拓展、附加功能全部无限制，由制作者自主设计开发。

（四）加分拓展功能（拉高评分差距，无强制要求）

车载屏幕自定义界面、电压监测、多档位调速、自主减震底盘、载物结构、灯光拓展、人机交互等任意自主拓展功能均可加分。

三、需提交全套筛选资料

1、设计说明书：自主底盘设计方案、STM32引脚分配、模块接线逻辑、手柄通信、屏幕显示程序思路；

2、CAD二维图纸：自主设计底盘、电机支架工程零件图；

3、三维源文件：全车自主建模装配模型源文件；

4、可现场演示完整小车实物；

四、筛选预约规则

1、本次筛选无集中统一考核、无集体筛选，学生小车成品、全套资料完成后，自主私下联系指导老师，一对一单独预约筛选时间；

2、筛选有效周期：开学第一周 8月31日—9月6日，仅限该时段内预约筛选；

开学第一周（8月31日—9月6日）内未主动预约、未完成小车一对一验收筛选，直接视为自动放弃本次筛选资格，不予补约、延后筛选。

五、现场筛选考核内容

1、实物核验：一对一现场操控小车，核验手柄基础行驶功能稳定即可，其余拓展功能不作硬性考核要求；

2、一对一单独答辩：核查建模尺寸、电路接线、代码逻辑、调试问题等全流程掌握度；

3、实操核验：一对一自主修改任意一项程序参数，独立改代码、烧录调试，核验真实编程调试能力，无指定修改内容、无统一考题。

六、百分制筛选评分标准

1、自主原创小车底盘建模设计：30分
2、STM32模块化自主搭接电路：25分
3、手柄遥控小车行驶功能稳定运行：20分
4、自主拓展优化功能：10分
5、独立答辩、精通全制作流程：15分

备注：全员一对一筛选打分，统一个人分数排名，择优录取前6名，纳入学科竞赛种子选手梯队培养。

七、耗材报销、梯队资助、奖励及退费规则

（一）本次筛选制作耗材报销

1、入选6名种子选手：单人制作耗材报销上限300元；双人临时搭档合计报销上限600元，凭采购凭证核销，超出金额自费；

2、未入选人员：本次制作所有耗材、元器件、板材费用全部自理，盈亏自负，无任何补贴。

（二）梯队后续备赛资助

入选种子梯队后，队内统一发放团队备赛资助共计1000元；费用报销划分规则如下：

1、专利申报、论文发表相关费用、超出1000元额度的额外备赛材料费：一律不予报销，全部个人承担；

2、学科竞赛报名费：实行获奖报销制，仅队伍取得省级三等奖及以上奖项，由学院统一报销对应赛事报名费；未取得省三及以上奖项，所有赛事报名费由个人自行承担。

（三）资助退费规则（队长负责制）

自领取1000元团队资助当日起，计算周期一年半：

1、周期内取得省级三等奖及以上竞赛成果：全队无需退还1000元资助，同时学院报销本次赛事报名费；

2、周期内无任何竞赛获奖成果：全队全额退还1000元资助，退款对接、统筹、清缴全部由队伍队长全权负责，同时所有赛事报名费不予报销，全部自费。

（四）梯队获奖激励

队伍斩获省级三等奖及以上奖项：
1、原有1000元团队资助无需退回；

2、队内每位成员，发放不低于500元专项个人奖励；

3、对应赛事报名费、材料、差旅等，由学院统一报销；不能报销的，我个人予以报销。

八、筛选流程

1、自主筹备：无专属实验室、无工具、无元器件借用，所有工具、物料、耗材全部学生自备；

2、完工预约：完成小车实物+全套资料后，8.31-9.6自行联系指导老师预约筛选；

3、打分筛选：线下答辩打分，按个人总分排序，录取前6人为竞赛种子选手；

4、结果告知：入选人员纳入梯队长期培养；落选人员点评短板，可参与下一轮筛选；

5、自愿参与：所有报名学生提前知悉全部资金、时间风险，自愿报名、风险自担。

6、落选帮扶：本次筛选未入选人员，若有意向跟随其他指导老师参与学科竞赛学习，本人可居中对接联络，协助匹配对应指导师资。

九、其他须知（统一禁止条款）

1、硬件：禁止使用一体式STM32开发板，仅限裸核心最小系统板；

2、结构：禁止直接购买成品整套小车底盘，底盘必须自主建模设计；

3、原创：禁止照搬网络现成整车电路、全套设计方案，电路、程序、结构需自主完成；

4、报销：成品玩具整车、成套改装车架，不在报销、资助范围内；仅省三及以上奖项，学院报销对应赛事报名费；论文、专利、超额材料费永久自费；

5、组队：禁止三人及以上组队，双人仅限制作搭档，筛选独立考核；

6、诚信：禁止代建模、代写代码、代组装调试，一经查实直接取消筛选资格；

7、物资：指导老师不提供场地、工具、元器件借用，全部物资学生自备。

十、梯队重要风险提醒

1、入选种子梯队后，备赛培养周期长达1-2年，时间投入、经济投入较大，严禁贪图耗材报销、补贴福利，头脑发热盲目报名蹭福利；

2、仅取得省级三等奖及以上成果，才可享受资助留存+单人500元以上奖励，同时学院报销赛事报名费，实现能力、荣誉、补贴双向收益；

3、一年半周期无竞赛获奖，报名费、专利论文费、超额材料费全部自费，还需由队长牵头退还全队1000元资助，个人最终产生经济亏损；

4、请结合课余时间、实操能力、经济条件审慎报名，立志长期深耕学科竞赛者方可参与本次筛选。

格子达中上传后

4月15号前上传完成后，请及时联系指导老师，进行审核检查并通过。

毕设阶段如何使用AI工具？

核心原则：AI仅为辅助工具，坚守学术诚信，所有使用情况需主动向指导教师披露并在论文中注明。

一、可使用场景

  1. 文献辅助：检索、关键词推荐、分类整理及初步摘要提取（需人工核验原文真实性并规范标注）。

  2. 英文文献翻译辅助：字面翻译、专业术语对应翻译（仅辅助理解，需人工校对优化，注明工具及修正说明）。

  3. 非核心设计辅助：辅助代码编写调试、推荐统计图表类型、绘制非考察内容图表（需人工审核优化）。

  4. 语言格式优化：语法纠错、语句流畅度调整、参考文献格式规范检查（不依赖其重构核心逻辑）。

  5. 思路拓展：拓宽选题思路、梳理研究框架、排查论证漏洞（核心方向与创新点源于自主思考）。

二、不可使用场景

  1. 生成核心内容：正文、致谢、研究结论、创新性总结，及研究方案、算法框架、数据分析讨论等关键环节。

  2. 篡改伪造成果：生成、伪造或篡改实验数据、调研结果、设计图纸、原创插图等原始素材。

  3. 涉密违规操作：向AI平台上传涉密数据、图片或核心研究内容（涉密课题禁用任何AI工具）。

  4. 答辩评审辅助：生成答辩稿、PPT核心内容，或答辩时借助AI实时辅助答题。

  5. 规避披露义务：未披露AI使用情况、披露信息不实，或直接照搬AI生成内容未人工修正。
