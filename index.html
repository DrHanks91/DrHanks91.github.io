本科毕业设计4-24会议自查清单

发表于 2026-04-13

关于毕业论文

整体

  • 题目与任务书一致，无擅自改动；
  • 研究内容、目标、技术路线清晰；
  • 工作量符合本科要求，不太空也不超纲；
  • 无抄袭、无代写、无篡改数据；

关于章节

  • 各章节表层递进，环环相扣，没有割裂与无关材料或者章节内容；不跳步、不缺章节；
  • 按照5章节划分。绪论内容为7-9页为宜，2-4章内容为31-39页为宜，第5章为2页为宜。5章节所有正文总计页数为40-48页为宜；
  • 第1和第5章（最后章节）不应有本章小节；
  • 目录章节第一级分别应为：中文摘要-英文摘要-第1章–至->第5章-参考文献-致谢-附录；

关于图、表、公式

  • 图表与题注相连，未出现跨页；且除了章节最后一页，不得出现大片空页；
  • 图表中文字统一为10-12pt；
  • 图-表题注均在正文中出现；
  • 图中若有子图，请用(a)-(b)此类文字进行标注；
  • 图表清晰、编号规范（图 1-1、表 2-1），且按顺序增加；
  • 公式、代码、流程图格式统一：公式居中，右侧编号1-1；
  • 表格统一使用三线表格形式；横线为：粗-细-粗；
  • 所有图片 / 表格自己制作，不直接盗用；

关于公式

  • 若使用word，请使用Mathtype生成，且有编号；

关于参考文献

  • 参考文献近五年文献数量应占总数量的2/3以上；
  • 英文参考文献数量不低于总参考文献的1/3；
  • 参考文献数量足够（50-60篇为宜）、格式规范（GB7714-2015）；
  • 参考文献引用格式正确，不标错、不漏标；

关于汇报PPT

  • 基于模版制作的PPT；
  • PPT 页数合适（10–20 页正文为宜）；
  • 讲稿控制在 5–8 分钟；
  • 重点：做了什么 → 怎么做 → 结果如何；
  • 提前预讲，不卡顿、不超时；
  • 准备好老师常问问题的答案；

毕设阶段如何使用AI工具？

发表于 2026-01-17

毕设阶段如何使用AI工具？

核心原则：AI仅为辅助工具，坚守学术诚信，所有使用情况需主动向指导教师披露并在论文中注明。

一、可使用场景

  1. 文献辅助：检索、关键词推荐、分类整理及初步摘要提取（需人工核验原文真实性并规范标注）。

  2. 英文文献翻译辅助：字面翻译、专业术语对应翻译（仅辅助理解，需人工校对优化，注明工具及修正说明）。

  3. 非核心设计辅助：辅助代码编写调试、推荐统计图表类型、绘制非考察内容图表（需人工审核优化）。

  4. 语言格式优化：语法纠错、语句流畅度调整、参考文献格式规范检查（不依赖其重构核心逻辑）。

  5. 思路拓展：拓宽选题思路、梳理研究框架、排查论证漏洞（核心方向与创新点源于自主思考）。

二、不可使用场景

  1. 生成核心内容：正文、致谢、研究结论、创新性总结，及研究方案、算法框架、数据分析讨论等关键环节。

  2. 篡改伪造成果：生成、伪造或篡改实验数据、调研结果、设计图纸、原创插图等原始素材。

  3. 涉密违规操作：向AI平台上传涉密数据、图片或核心研究内容（涉密课题禁用任何AI工具）。

  4. 答辩评审辅助：生成答辩稿、PPT核心内容，或答辩时借助AI实时辅助答题。

  5. 规避披露义务：未披露AI使用情况、披露信息不实，或直接照搬AI生成内容未人工修正。
